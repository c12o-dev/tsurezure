記事は Markdown で書きます。見出し、リスト、表、リンクといった標準の記法に加えて、このテンプレートでは `remark-directive` の記法でいくつかの部品を使えます。この記事はその一覧です。

## 注記ブロック

`:::` で囲んだ部分が注記になります。種類は `note`、`tip`、`important`、`warning`、`caution` の 5 つです。

:::note
補足の情報です。読み飛ばしても本文の理解には困らない内容を書きます。
:::

:::tip
知っておくと作業が楽になることを書きます。
:::

:::important
手順を進める前に必ず確認してほしいことを書きます。
:::

:::warning
失敗すると手戻りが出る操作の前に置きます。
:::

:::caution
データの消失など、取り返しのつかない結果につながる操作の前に置きます。
:::

`[` `]` で見出しを付けられます。

:::tip[見出しを付けた注記]
`:::tip[見出し]` と書くと、種類名の代わりに見出しが表示されます。
:::

GitHub の記法もそのまま使えます。

> [!NOTE]
> `> [!NOTE]` で始まる引用は、`:::note` と同じ注記になります。

## GitHub カード

`::github{repo="owner/repo"}` と書くと、リポジトリへのカードになります。説明文やスター数は、閲覧時にブラウザから GitHub API を呼んで埋めます。

::github{repo="withastro/astro"}

API は未認証だと 1 時間に 60 回までしか呼べません。上限に達したときは、カードはリンクとしてだけ表示されます。

## 地図カード

`::googlemap` は地図へのリンクをカードにします。`title`、`addr`、`image` は省略できます。`image` を指定しないと、画像の代わりにピンの図形が出ます。

::googlemap{url="https://maps.google.com/?q=Tokyo+Station" title="東京駅" addr="東京都千代田区丸の内1丁目"}

## 伏せ字

`:spoiler[ここに文字]` と書くと、:spoiler[マウスを重ねるまで読めない文字] になります。

## 標準の記法

表とタスクリストは GitHub Flavored Markdown の記法です。

| 記法 | 用途 | 出力 |
| --- | --- | --- |
| `:::note` | 注記 | `<blockquote>` |
| `::github` | リポジトリのカード | `<a>` |
| `:spoiler[]` | 伏せ字 | `<span>` |

- [x] 見出しを `##` から始める
- [x] 画像に代替テキストを書く
- [ ] 公開前に `pnpm build` で確認する

見出しは `##` から始めます。`#` は記事のタイトルに使われているためです。`##` と `###` は右側の目次に載ります。
