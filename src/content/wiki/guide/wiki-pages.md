記事（Posts）は書いた日付に紐づき、公開したあとはあまり書き換えません。Wiki はその逆で、1 つの概念に 1 ページを割り当て、新しく分かったことがあれば同じページに書き足します。

## ファイルの置き場所

Wiki のページは `src/content/wiki/<topic>/<page>.md` に置きます。フォルダ名がトピックになり、URL は `/wiki/<topic>/<page>/` です。

```shellsession
$ pnpm new wiki web/cache-control
```

このコマンドは、今日の日付を入れたひな形を作ります。同じ名前のページがすでにあるときは、新しく作らずにエラーで止まります。

トピックの表示名は `src/config.ts` の `wiki.topics` に書きます。書いていないトピックは、フォルダ名がそのまま表示されます。

## frontmatter

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| `title` | ○ | ページの名前。概念の名前にする |
| `summary` | ○ | 一文の要約。ページ上部の枠と一覧に出る |
| `created` | ○ | ページを作った日 |
| `updated` | ○ | 最後に書き足した日。一覧の並び順に使う |
| `tags` | | タグの配列 |
| `sources` | | 参考にした URL の配列。ページの末尾に並ぶ |
| `publishedTo` | | このページから記事を書いたときの、記事の URL |
| `draft` | | `true` にすると本番のビルドに含まれない |

## 書き足すときの約束

- 書き足したら `updated` を更新する。Wiki のトップの更新履歴は、この日付の新しい順に並ぶ
- ページの名前は、質問の形ではなく概念の名前にする。「Cache-Control とは」ではなく「Cache-Control の基本」
- 1 ページが長くなったら、節を別のページに分けて、元のページからリンクする

:::tip
Wiki を使わない場合は、`src/config.ts` の `features.wiki` を `false` にします。Wiki のページ、ナビゲーションのリンク、トップページの Wiki 欄が出なくなります。
:::
